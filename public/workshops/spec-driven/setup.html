Back to overview Setup — no paid subscription needed

Setup ~15 min

You need two things: a coding agent (the tool in your terminal) and a model (the brain it talks to). Both can be completely free — no paid LLM subscription required.

The two layers: OpenCode is the free, open-source agent. It is model-agnostic, so you pick a free model provider below. Facilitators are here to help if anything gets stuck.

1 · Install OpenCode (the agent)

Pick your operating system.

  1. Install OpenCode with the official script:
    Copy
    curl -fsSL https://opencode.ai/install | bash

    Prefer npm? npm install -g opencode-ai works too (needs Node.js 18+).

  2. Restart your terminal, then confirm it is on your PATH:
    Copy
    opencode --version
  1. Install OpenCode with Scoop (recommended) …
    Copy
    scoop install opencode
    … or with Chocolatey, or npm:
    Copy
    choco install opencode
# or
npm install -g opencode-ai

    No package manager? Grab the Windows binary from the releases page. Windows users often have the smoothest time inside WSL2 (Ubuntu) — if you use WSL, follow the Ubuntu tab instead.

  2. Open a new terminal (PowerShell) and confirm:
    Copy
    opencode --version

Then add the file-tree plugin

A navigable file tree in the sidebar so you can see and preview the specs and code as you work. Same command on Ubuntu and Windows.

  1. Install it with OpenCode's built-in command. This is a TUI plugin, so let OpenCode wire it up — don't hand-edit the config. Run:
    Copy
    opencode plugin --global opencode-file-tree

    The command installs the package and registers it in the right place (a tui.json next to your config). Drop --global to add it to the current project only.

  2. Restart OpenCode. The file tree appears in the sidebar — click a folder to expand it, click a file to preview it inline.
Don't add it to opencode.json by hand. The top-level "plugin" array is for server plugins; putting a TUI plugin there fails to load (must default export an object with server()) and no sidebar appears. Always use the opencode plugin command above.

2 · Connect a free model (the brain)

Choose one. Start with the default — the fallbacks are there if signup, connectivity, or your laptop get in the way.

Default

Google Gemini (free tier)

Best quality-for-effort: one free API key, no special hardware.

  1. Get a free key at aistudio.google.com/apikey (Google account).
  2. In OpenCode run /connect, choose Google, paste the key.
  3. Run /models and pick Gemini 3.1 Flash Lite — medium. It gives reasonable results for this workshop while using few tokens, so you stay well inside the free tier.
Fallback A

GitHub Copilot

Already have Copilot (free for students & OSS maintainers)? Zero setup.

  1. In OpenCode run /connect, choose GitHub Copilot.
  2. Open github.com/login/device and enter the code shown.
  3. Run /models and pick a model.
Fallback B

Local model (Ollama)

Offline & no signup. Needs a capable laptop (~8 GB free RAM/VRAM).

  1. Install Ollama, then pull a coding model:
    Copy
    ollama pull qwen2.5-coder
  2. Point OpenCode at it via opencode.json (OpenAI-compatible endpoint):
    Copy
    {
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama (local)",
      "options": { "baseURL": "http://localhost:11434/v1" },
      "models": { "qwen2.5-coder": { "name": "Qwen2.5 Coder" } }
    }
  }
}
  3. Run /models and pick Qwen2.5 Coder.

3 · Readiness check

Navigate into any empty folder and start OpenCode:

Copy
mkdir sdd-workshop && cd sdd-workshop
opencode

Type a message like "Say hello and tell me which model you are." and press Enter.

✅ You're ready when the agent replies in the terminal. Tip: press Tab to toggle Plan mode — you'll use it a lot today, because in spec-driven development we settle the plan before writing code.

Stuck? Grab a facilitator, or ask the agent itself to help debug the setup once it responds.
