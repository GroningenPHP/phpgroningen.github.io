# Groningen Skyline – Image Manifest

Reference for anyone (human or AI) who edits the homepage hero skyline.
**Always edit `groningenphp-skyline-hero.svg`, then run `./build.sh`.** Never hand-edit
the files in `public/images/`; they are generated.

## Files

| File | Role |
|---|---|
| `groningenphp-skyline-hero.svg` | **Source of truth.** Editable, readable SVG with named groups. |
| `groningenphp-skyline-ultrawide-transparent (2).svg` | Original illustration this was derived from (unmodified, for reference). |
| other files in this folder (`*.svg`, `*.png`) | Original downloads / alternative crops. Not used by the site. |
| `make-night.py` | Generates the night variant: darkens all colours towards navy and "lights" ~60% of the windows. |
| `svgo.config.cjs` | SVGO config (preset-default, multipass, **keeps `viewBox`**; removing it breaks scaling). |
| `build.sh` | Runs the full pipeline below. |
| `../../public/images/groningenphp-skyline.svg` | Built day version (used by CSS). |
| `../../public/images/groningenphp-skyline-night.svg` | Built night version (used by CSS when `data-time="night"`). |
| `../../public/images/groningenphp-skyline-outline.svg` | **Footer outline.** Hand-written single `<path>` line drawing (see "Footer outline" below). Not generated by `build.sh`. |

### Where the images are used

- `public/css/styles.css`, section `/* Hero Section */`:
  - `.hero-bg` is the background image, `bottom center / cover`, 68% of the hero height.
  - The image is softened via `--hero-skyline-filter` and `--hero-skyline-opacity` (about 0.5 by day, 0.95 at night).
  - Mobile (`max-width: 768px`) uses `background-position: 75% bottom` so the Martinitoren stays in view.
- `public/js/hero-season.js` sets `data-season` (autumn/winter/spring/summer) and `data-time` (day/night).
  - It uses Europe/Amsterdam time.
  - You can override it for testing with `?season=winter` and `?time=night`.

## Build

```bash
cd resources/GroningenSkyline
./build.sh   # = make-night.py + svgo for day and night → public/images/
```

Browsers cache the SVGs aggressively, so do a hard refresh (or disable the cache) when you check your changes.

## Coordinate system

- `viewBox="0 0 5120 1080"`, `preserveAspectRatio="xMidYMax slice"`.
- **Ground / waterline is y ≈ 962.** Everything below it is canal water with reflections.
- On desktop the full width is visible (the image scales by width).
- On mobile only a slice around x ≈ 3000–4400 is visible (75% crop).

### Layer order (back → front)

1. `far-layer`: pale distant blocks and flats.
2. `mid-layer`: medium-tone rooftops.
3. Landmark towers: `akerk`, `martinitoren`, `forum`, `tasmantoren`.
4. `front-layer`: gabled canal houses. It also contains `windmill` and `hoofdstation`.
5. `dot`, `groninger-museum` with `museum-reflection`, and the water strips.
6. `peerd-van-ome-loeks`, trees, cyclists, and `boat` (frontmost).

New background landmarks go **before `<g id="front-layer">`** so the canal houses overlap their base.

### Layout constraints

- **Text-safe zone:** hero text and buttons sit centred over roughly x 1300–3800. Keep tall elements (top y < ~600) out of this zone so they don't fight with the heading. Low buildings are fine.
- **Mobile crop:** only the right-centre (around the Martinitoren) is visible. Don't move the Martinitoren without updating the mobile `background-position`.
- The far left (x < 400) and far right (x > 4500) can be partially hidden on narrower desktop ratios.

## Palette (day source)

| Use | Colour |
|---|---|
| Dark body / main silhouettes | `#0B2F75` |
| Brick / mid tone | `#0E3A8F` |
| Stone / lighter faces | `#21479A` |
| Columns / highlights | `#2E5BB5` |
| Roofs | `#0A2B6B` |
| Windows | `#3E68C0`, `#3A4F7A` |
| Clock face | `#D6E1F3` |
| Flower boxes | `#E68FB0` |

The site desaturates the whole image (`saturate(60%)`) and lowers opacity by day, so the source colours look stronger in the file than on the page.

### Night window rule (`make-night.py`)

- Only `<rect>` elements that are **≤ 40×60** and filled with `#3E68C0` or `#3A4F7A` count as windows.
- 60% of them, chosen at random with a fixed seed of 42, turn warm yellow. Everything else is darkened towards navy.
- So: **draw windows as small rects in those colours** if they should light up at night.

Settings at the top of the script: `NIGHT=(11,21,48)`, `DARKEN=0.55`, `LIT_RATIO=0.6`, `SEED=42`.

## Footer outline

`public/images/groningenphp-skyline-outline.svg` is a minimal, one-line version of the same skyline.

- **Shape:** a single stroked `<path>` with no fill.
  - Stroke `#8C96A8`, 1.5px, with `vector-effect="non-scaling-stroke"`.
- **Coordinates:** `viewBox="0 0 1200 100"`. The ground line sits at y = 99 so it lines up with the bottom edge of the image.
- **Landmarks, left → right (same order as the hero):**

| Landmark | x |
|---|---|
| Windmill (an X of sails) | 40–80 |
| Tasmantoren gate | 108–170 |
| Hoofdstation arch | 180–262 |
| A-kerk spire | 290–358 |
| Groninger Museum | 398–474 |
| Stadhuis pediment | 534–626 |
| Forum | 750–804 |
| DOT dome | 812–864 |
| Martinitoren and church (tallest, top y = 2) | 916–1018 |

  Small gabled rooflines (y 76–84) fill the gaps in between.
- **Used by** `.footer-bottom::before` in `styles.css`.
  - It is drawn 64px high, centred, and replaces the old divider border.
  - A full-width 1.5px `linear-gradient` line continues the ground line.
  - Overall opacity is 0.55.
  - Mobile uses `background-position: 80%` so the Martinitoren stays visible.
- **Editing:** keep it one continuous line. Backtracking along the same segment is fine (the windmill sails and the Tasmantoren opening do this).

4. Added the Tasmantoren on the left, behind the windmill and front houses.
